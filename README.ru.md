# Фикс для Tides of War

[English](README.md) | **Русский**

Неофициальный фикс для **Tides of War** (Devil's Thumb Entertainment, 1998) на современной Windows.
Не связан с разработчиками и издателем игры. Фикс содержит только собственный код — нужна своя копия игры.

## Что исправляет

- **Суда с текстурами**, а не сплошь красные (Direct3D RGB вместо Ramp, белый цвет вершин).
- **Целочисленное масштабирование ×2/×3/×4** игры 640×480, чёткие пиксели, окно по центру; мышь, диалоги, кнопки, шрифты и курсор масштабируются вместе с картинкой.
- **Полный экран без рамки** с чёрными полями (опция полного экрана в игре); разрешение рабочего стола не меняется.
- **Запуск из своей папки** двойным щелчком — без диска `SUBST` и без режимов совместимости.
- **Сохранения и настройки рядом с игрой** (`saves\`), ничего не пишется в реестр и в Program Files.
- **Плавное движение** других судов (каждый шаг игры рисуется сразу) и настраиваемый **темп игры**.
- **Плавное движение с частотой обновления монитора** в сценах миссии (Direct3D 11 с вертикальной синхронизацией;
  Windows 7 SP1+, с возвратом к GDI).
- **Больше не грузит ядро процессора на 100%:** в ожидании сообщений игра спит, а не опрашивает очередь по кругу.
- Пропускается предупреждение «рассчитано на Windows 95».

Каждое исправление отключается в `tow_fix.ini`.

## Требования

- Windows 10 или 11 (Windows 7 SP1 — цель, но ещё не проверена).
- Tides of War, **английский выпуск 1998 года** — патчер принимает только такие `TOW.exe` (SHA-256):
  - `4cd1a3ddad2007e5c09fd55b02922ff59fdd20434d95e433e6e85ce7cb327967` — оригинал;
  - `9dcf3f69bf505208e9826e6b9a56bb2356e2a7794debdc3ac589c1fbfc0a8289` — оригинал с no-CD патчем.
  Другие сборки (локализации, другие патчи) пока не поддерживаются — сообщите их хеш.
- **Должны быть установлены и зарегистрированы элементы ActiveX игры `Anibtn32.ocx` и `Threed32.ocx`.**
  Это делает установщик с оригинального диска. Если игра установлена не с диска, возьмите
  [«фикс для Windows XP» с old-games.ru](https://www.old-games.ru/game/download/get.php?fileid=2796&modal=1):
  скопируйте оба файла `.ocx` в папку игры и один раз запустите его `setup.bat` **от имени администратора**.
  Без них игра падает при открытии порта (Trade).
- Игра по-прежнему проверяет наличие своего диска.

## Установка

1. Скачайте `tow_fix-<версия>.zip` из [Releases](../../releases) и распакуйте в папку игры (рядом с `TOW.exe`).
2. Дважды щёлкните `tow_patch.exe` и подтвердите. Он проверит версию игры, сохранит копию `TOW.exe.bak`
   и добавит `tow_fix.dll` в таблицу импорта `TOW.exe`.
3. Запускайте игру как обычно — `TOW.exe`.

Чтобы удалить фикс, снова дважды щёлкните `tow_patch.exe` и выберите восстановление `TOW.exe.bak`.
Из командной строки: `tow_patch.exe [--check | --restore] [путь\TOW.exe]`.

## Настройки

**Ничего настраивать не нужно — всё уже включено и проверено.**
Не меняйте `tow_fix.ini`, если не уверены, что делаете: неверное значение может вернуть красные суда или сломать
интерфейс. Если что-то испортили — возьмите `tow_fix.ini` из архива выпуска заново.

Можно менять без риска: `[game_speed] percent` (темп игры) и `[scaling] factor` (увеличение).

Для справки, основные ключи (`1` — включено, `0` — выключено):

| Секция | Ключ | По умолчанию | Что делает |
|---|---|---|---|
| `[scaling]` | `factor` | `auto` | `0` — выкл., `2`..`4` или `auto` (наибольший, что помещается на экран) |
| `[scaling]` | `fullscreen` | `borderless` | опция полного экрана в игре: `borderless` или `off` (всегда окно) |
| `[game_speed]` | `percent` | `80` | темп игры, 100 — исходный шаг 62 мс |
| `[rgb_device]`, `[white_diffuse]` | `enabled` | `1` | суда с текстурами |
| `[idle_wait]` | `enabled` | `1` | сон вместо опроса очереди (нагрузка CPU) |
| `[save_redirect]`, `[registry_guard]` | `enabled` | `1` | сохранения и настройки в `saves\`, без записи в реестр |
| `[d3d11]` | `enabled`, `smooth` | `1` | установите 0, чтобы отключить путь D3D11, если возникнут проблемы |
| `[wake]` | `enabled` | `1` | след за каждым судном |
| `[timer_guard]` | `enabled` | `1` | мир не замирает после частых кликов по судам |

Лог пишется в `tow_fix.log` рядом с `TOW.exe` — прикладывайте его к сообщениям об ошибках.

## Сборка из исходников

Visual Studio 2022 Build Tools (компилятор C x86, Windows SDK). Запустите `build.cmd`, результат — в `build\`.
`format.cmd` и `lint.cmd` используют clang-format/clang-tidy из Visual Studio. Подробнее — [docs/building.md](docs/building.md).
